# StaveWave Notation feedback

Public bug reports and feature requests for the StaveWave Notation Mac app.
This repository contains reporting instructions only; application source code is maintained separately.

- [Report a bug](https://github.com/mikerewak/notation-feedback/issues/new?template=bug_report.yml)
- [Suggest an improvement](https://github.com/mikerewak/notation-feedback/issues/new?template=feature_request.yml)
- [Search existing reports](https://github.com/mikerewak/notation-feedback/issues)
- [Report a security vulnerability privately](https://github.com/mikerewak/notation-feedback/security/advisories/new)

In the app, use **Help → Report a Problem…** when available. Review the report before opening GitHub.
A GitHub account is required to submit an issue. You can also copy or save the report locally.

## What makes a useful report

Describe what you did, what you expected, and what happened. Include your app version and macOS
version. A small reproducible example is more useful than an entire project. For a crash or lost
work, describe the last action and whether reopening the document recovered it.

**Issues and attachments are public.** Remove personal details, account information, local file
paths, and confidential or copyrighted score material before posting. Attach a score or screenshot
only if you have permission to share it. Do not post credentials, full unreviewed logs, or security
vulnerabilities here; use the private security reporting link above.

## Triage

New reports receive the `triage` label. Maintainers reproduce and prioritize them, ask for missing
information when necessary, and link duplicate reports. A fix is closed with its release version
when available. A submitted request is not a promise of a feature or release date.
