# Security reports

Please report security vulnerabilities through [GitHub private vulnerability reporting](https://github.com/mikerewak/notation-feedback/security/advisories/new).
Do not open a public issue containing exploit details, credentials, private documents, or personal information.

Include the affected app version, reproduction steps, and potential impact. Share only the minimum
information needed to investigate. Ordinary crashes and feature requests belong in the public issue tracker
after private information has been removed.
